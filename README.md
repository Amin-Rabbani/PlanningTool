# Sprint Room

نسخه‌ی جدید ابزار پلنینگ اسپرینت با یک کتابخانه‌ی مرکزی برای همه‌ی اسپرینت‌ها ساخته شده است. داشبورد Angular است و صفحه‌ی پلنینگ موجود (با تمام قابلیت‌های Jira، ظرفیت، AI، گزارش و import/export) در `public/planner.html` نگه‌داری می‌شود تا داده‌های قبلی و رفتارهای آن از بین نرود.

## اجرا در حالت آفلاین

```bash
npm install
npm run build
python3 jira_proxy.py
```

سپس `http://127.0.0.1:8765/index.html` را باز کنید. برای محیطی که وابستگی‌های npm از قبل نصب شده‌اند، اجرای `jira_proxy.py` فقط فایل‌های build‌شده و API محلی را سرو می‌کند و برای ساخت/خواندن اسپرینت به اینترنت نیاز ندارد.

هر اسپرینت در اولین ساخت به‌صورت فایل مستقل در `data/<نام-اسپرینت>.json` ایجاد می‌شود. تغییرات صفحه‌ی پلنینگ هم با فاصله‌ی کوتاه در همان فایل ذخیره می‌شود؛ توکن‌های Jira و OpenRouter مانند قبل در فایل ذخیره نمی‌شوند.
